# Contributing to AllStarLink

Thank you for helping improve AllStarLink. Individual repositories may add
their own contribution details; where they do, those take precedence for that
project.

## AI Use

AI-assisted contributions are welcome. AI tools are neither required nor
prohibited, but you are the author and are fully responsible for anything you
submit: you must understand it, have tested it, and be able to defend it in
review without deferring to the tool. AI-assisted work is held to the same
standard as any other contribution.

This applies to code, documentation, issue reports, and review comments. The
policy is [ASL003 - AI Use Practice](https://allstarlink.org/ai/)
([canonical text](https://github.com/AllStarLink/Standards/blob/main/ASL003-AI_Use_Practice.md)).
Please read it; this section is only a summary.

- **Disclosure.** When there is any AI involvement, for example an AI-enabled
  IDE or development environment, some code generation, or AI-assisted
  debugging, add a commit trailer in this format:

  ```
  Assisted-by: <tool name> <model or version>
  ```

  For example:

  ```
  Assisted-by: Claude claude-sonnet-5
  ```

  Trivial use (autocomplete, spell or grammar checking, translation, boilerplate
  expansion) does not need to be disclosed. Trailers are informational and do
  not shift responsibility from you.
- **Bulk or drive-by changes.** Mass refactors, style rewrites, whitespace
  cleanup, and automated "fix" submissions generated by AI tools need
  agreement from the maintainers before you submit them.
- **Reports.** Verify and reproduce any problem yourself before reporting it.
  AI-assisted security reports need a reproducible demonstration and must go
  through the [security reporting channel](SECURITY.md), never a public issue.
- **Questions from maintainers.** Maintainers may ask whether and how AI tools
  were used. Please answer honestly.
